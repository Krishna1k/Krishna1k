# 🔴 PART A — CORE BASICS (MISS MAT KARNA)

### 🔴 1. Magnet basic
- 🔴 N aur S pole. **Like poles repel, unlike attract**. Magnetic field = asar wala area. Compass N-S dikhati.

### 🔴 2. Current aur Circuit
- 🔴 Current = charge flow (+ve→−ve). Taar me current → magnetic effect. **Solenoid** = coil jaisa lapeta taar.

### 🔴 3. Direction
- 🔴 **dot (·)** = baahar aapki taraf; **cross (×)** = andar. Perpendicular = 90°.

### 🔴 4. Maths/Geometry
- 🔴 Concentric circles, left/right/up/down direction (Fleming ke liye).

### 🔴 5. AC vs DC
- 🔴 **DC** ek disha (cell); **AC** disha badalti (ghar 50 Hz).

# PART B — CHAPTER KA MAIN CONTENT

### 1. 🟢 Magnetic Field + Field Lines
- 🟢 **Oersted:** current → magnetic field. Lines: bahar **N→S** (closed loops), **cross nahi karti**, paas=strong.

### 2. 🟢 Field due to Straight Conductor
- 🟢 Seedhe taar ke around **concentric circles**. **Right Hand Thumb Rule:** angootha current me, ungli curl = field.

### 3. 🟢 Solenoid + Electromagnet — VERY IMPORTANT
- 🟢 Solenoid field = **bar magnet jaisa** (ek sira N, doosra S, andar uniform).
- 🟢 **Electromagnet** = solenoid + soft iron core (temporary; current band → magnetism khatam). Soft iron jaldi magnetise/demagnetise.

### 4. 🟢 Force on Conductor — TOP EXAM AREA
- 🟢 Field me current wale taar par **force** (max jab perpendicular).
- 🟢 **Fleming's LEFT Hand Rule:** First=Field, Centre=Current, Thumb=Force. Memory **"FBI"** (thumb-Force, first-B/field, centre-I). → **Motor** ka base.

### 5. 🟢 Electric Motor — TOP EXAM AREA
- 🟢 Electrical → **mechanical**. Coil par force (Fleming left) → ghoomti.
- 🟢 **Split ring/commutator** = har aadhe chakkar me current palat-ta → ek disha me ghoomti. Use: fan, mixer, pump.

### 6. 🟢 Electromagnetic Induction — TOP EXAM AREA
- 🟢 **Faraday:** changing magnetic field → coil me current (bina battery). Tez movement → jyada current.
- 🟢 **Fleming's RIGHT Hand Rule** (induced current). Memory: **Motor=LEFT, Generator=RIGHT**.

### 7. 🟢 Electric Generator — VERY IMPORTANT
- 🟢 **Mechanical → electrical** (motor ka ulta). Coil ghumao → EMI.
- 🟢 **AC generator: slip rings**; **DC generator: split ring**. Ghar supply AC (220V, 50Hz).

### 8. 🟢 Domestic Circuit + Safety
- 🟢 3 taar: **Live** (red/brown), **Neutral** (black/blue), **Earth** (green - safety).
- 🟢 **Earthing:** metal body earth se jodna → leakage current zameen me → shock se bachav.
- 🟢 **Short circuit** (live-neutral touch → bahut current); **Overloading** (bahut appliance). **Fuse** live wire me (kam m.p.) = safety.
