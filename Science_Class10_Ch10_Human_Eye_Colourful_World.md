# PART B — CHAPTER KA MAIN CONTENT

### 1. 🟢 Human Eye Structure — VERY IMPORTANT (ratta)
- 🟢 **Cornea** (max refraction), **Iris** (pupil control), **Pupil** (light control), **Eye lens** (convex, fine focus), **Ciliary muscle** (lens shape), **Retina** (real+inverted image; **Rods** dim light, **Cones** rang), **Optic nerve** (brain tak).

### 2. 🟢 Power of Accommodation
- 🟢 Lens ka **focal length badalna**. Door → muscle dheele, lens patla, f badi. Paas → muscle tight, lens mota, f chhoti.
- 🟢 **Near point = 25 cm**, **Far point = infinity** (normal eye).

### 3. 🟢 Defects of Vision — TOP EXAM AREA
- 🟢 **(A) Myopia** (paas dikhta, door nahi): image retina ke **aage**. Sudhaar: **Concave lens**.
- 🟢 **(B) Hypermetropia** (door dikhta, paas nahi): image retina ke **peeche**. Sudhaar: **Convex lens**.
- 🟢 **(C) Presbyopia** (budhapa, dono dikkat): **Bifocal lens**.
- 🟢 Memory: *"Myopia = Minus (concave); Hypermetropia = Plus (convex)"*. Cataract = lens cloudy (surgery).

### 4. 🟢 Prism + Dispersion — TOP EXAM AREA
- 🟢 **Dispersion** = white light → 7 colours (VIBGYOR). Violet sabse zyada bend, Red sabse kam.
- 🟢 **Recombination:** ulta prism → wapas white (Newton).

### 5. 🟢 Rainbow
- 🟢 Paani ki boondein prism jaisa → **refraction + dispersion + internal reflection**. Suraj peeche, boondein saamne.

### 6. 🟢 Atmospheric Refraction
- 🟢 **Tare timtimana** (layers se light mudti); **suraj 2 min pehle** dikhna; sunset par oval/laal.

### 7. 🟢 Scattering of Light — TOP EXAM (VERY IMP)
- 🟢 **Tyndall effect** = colloid/dust me light path dikhna (jungle dhundh, torch beam).
- 🟢 **(A) Sky neela:** blue (chhoti wavelength) zyada scatter.
- 🟢 **(B) Sunset/sunrise laal:** zyada hawa paar → blue scatter ho jaata, **red** bachta.
- 🟢 **(C) Space me aasman kaala:** hawa/molecule nahi → no scattering.
- 🟢 **(D) Danger signal red:** red kam scatter → door se saaf dikhta.
