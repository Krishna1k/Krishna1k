# 🔴 PART A — CORE BASICS (MISS MAT KARNA)

### 🔴 1. Light basic
- 🔴 Light seedhi line me (rectilinear). **Reflection** = surface se takrakar wapas. **Image** = bana roop.

### 🔴 2. Angle aur Normal
- 🔴 **Normal** = surface par 90° line. **i** (angle of incidence), **r** (angle of reflection).

### 🔴 3. Real vs Virtual image
- 🔴 **Real** = screen par pakad sakte, hamesha **inverted (ulti)**. **Virtual** = screen par nahi, hamesha **erect (seedhi)**.

### 🔴 4. Concave vs Convex
- 🔴 **Concave** = andar dhasaa (chammach andar). **Convex** = bahar ubhaar.

### 🔴 5. Maths basics
- 🔴 Sign (+/−) ka dhyan, 1/f reciprocal, cross-multiply se v/u nikalna.

# PART B — CHAPTER KA MAIN CONTENT

### 1. 🟢 Laws of Reflection
- 🟢 **(1) i = r** (2) incident, reflected, normal ek plane me.
- 🟢 **Plane mirror image:** virtual, erect, same size, peeche utni door, **laterally inverted** (AMBULANCE ulta likha).

### 2. 🟢 Spherical Mirrors — TOP EXAM AREA
- 🟢 **Concave** = converging (kiranein milati); **Convex** = diverging (failati).
- 🟢 Terms: Pole (P), Centre of curvature (C), Radius (R), Focus (F). **R = 2f**.

### 3. 🟢 Concave Mirror Image (object position se) — VERY IMPORTANT
| Object | Image | Nature |
|---|---|---|
| Infinity | F par | Real, inverted, point |
| Beyond C | C–F beech | Real, inverted, chhota |
| At C | At C | Real, inverted, same |
| C–F beech | Beyond C | Real, inverted, bada |
| At F | Infinity | Real, inverted, bahut bada |
| F–P beech | Peeche | **Virtual, erect, bada** |
- 🟢 Uses: shaving/makeup, torch/headlight reflector, dish antenna, solar furnace.

### 4. 🟢 Convex Mirror Image
- 🟢 **Hamesha virtual, erect, chhota** (peeche). Uses: **gaadi side/rear-view mirror** (wider field), security mirror.

### 5. 🟢 Mirror Formula + Magnification — TOP EXAM (numericals)
- 🟢 **1/v + 1/u = 1/f** ; **m = h'/h = −v/u**.
- 🟢 **Sign convention:** pole se naapo; saamne −ve, peeche +ve; u hamesha −ve; concave f −ve, convex f +ve.
- 🟢 m −ve → real+inverted; m +ve → virtual+erect. |m|>1 bada, <1 chhota.

### 6. 🟢 Refraction — TOP EXAM AREA
- 🟢 Light medium badalne par mud-ti (speed change). Rare→dense: normal ki **taraf**; dense→rare: normal se **door**; 90° par seedha.
- 🟢 Glass slab → parallel shift. Pencil paani me tedhi, pool kam gehra, tare timtimate.

### 7. 🟢 Refractive Index
- 🟢 **n = c/v** (vacuum speed / medium speed). Zyada n = zyada dense + zyada mudti. Water 1.33, glass 1.5, **diamond 2.42**.

### 8. 🟢 Lenses — TOP EXAM AREA
- 🟢 **Convex** = beech mota, converging. **Concave** = beech patla, diverging.
- 🟢 Convex image: beyond 2F→2F-F chhota; at 2F→same; 2F-F→beyond 2F bada; at F→infinity; F-O→virtual erect bada.
- 🟢 **Concave lens: hamesha virtual, erect, chhota.**
- 🟢 **Lens formula: 1/v − 1/u = 1/f** ; **m = v/u**. Convex f +ve, concave f −ve.

### 9. 🟢 Power of Lens
- 🟢 **P = 1/f** (f metre me), unit **dioptre (D)**. Convex +ve, concave −ve. **Combination: P = P₁+P₂+...**
