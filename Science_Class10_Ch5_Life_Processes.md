# PART B — CHAPTER KA MAIN CONTENT

### 1. 🟢 Life Processes
- 🟢 4 main: **Nutrition, Respiration, Transportation, Excretion**.

### 2. 🟢 NUTRITION — TOP EXAM AREA
- 🟢 **Photosynthesis:** `6CO₂ + 6H₂O --(sunlight, chlorophyll)--> C₆H₁₂O₆ + 6O₂`. Site = **chloroplast**.
- 🟢 Steps: (1) chlorophyll light absorb (2) water tootna + ATP (3) CO₂ reduce → glucose.
- 🟢 **Stomata** = gas exchange + transpiration; guard cells khol/band karte.
- 🟢 Heterotrophic types: **Saprophytic** (fungi), **Parasitic** (Cuscuta), **Holozoic** (Amoeba, human).
- 🟢 Amoeba: pseudopodia → food vacuole. Steps: Ingestion, Digestion, Absorption, Assimilation, Egestion.

### 3. 🟢 Human Digestive System — VERY IMPORTANT
- 🟢 Mouth → Oesophagus → Stomach → Small intestine → Large intestine → Anus.
- 🟢 **Mouth:** salivary amylase/ptyalin → starch→maltose.
- 🟢 **Stomach:** HCl (bacteria maare + acidic), **pepsin** (protein), mucus (deewar bachata).
- 🟢 **Small intestine** (max digestion+absorption): **bile** (fat emulsify + alkaline), pancreas (trypsin/lipase/amylase), **villi** (absorption surface area).
- 🟢 **Large intestine:** paani absorb, waste egestion.

### 4. 🟢 RESPIRATION — VERY IMPORTANT
- 🟢 **Aerobic** (O₂, mitochondria, zyada energy): glucose → CO₂+H₂O+energy.
- 🟢 **Anaerobic:** yeast → ethanol+CO₂ (fermentation); muscle → **lactic acid** (cramp/dard).
- 🟢 Glucose → cytoplasm me **pyruvate**; O₂ ho → mito CO₂+H₂O, na ho → lactic acid/ethanol. **Mitochondria = power house**.
- 🟢 Path: Nostrils→Pharynx→Larynx→Trachea→Bronchi→Bronchioles→**Alveoli**.
- 🟢 **Alveoli** = gas exchange (surface area zyada, patli deewar, blood vessel). Trachea me cartilage ring. **Haemoglobin** O₂ carry karta.

### 5. 🟢 TRANSPORTATION (Human) — TOP EXAM AREA
- 🟢 **Heart 4 chambers:** 2 atria + 2 ventricles. Right = de-oxygenated, Left = oxygenated.
- 🟢 **Double circulation:** blood 2 baar heart se (pulmonary + systemic). Path: Body→RA→RV→Lungs→LA→LV→Body.
- 🟢 **Left ventricle deewar sabse moti** (poore body me high-pressure pump). Valves backflow rokte.
- 🟢 **Artery** (heart se, oxygenated except pulmonary, moti, no valve); **Vein** (heart ko, de-oxy except pulmonary, patli, valves); **Capillary** (sabse patli, exchange).
- 🟢 Blood: Plasma, RBC (haemoglobin), WBC (bachav), Platelets (clotting). **Lymph** = fat absorb + defence.
- 🟢 **Plants:** **Xylem** (paani+mineral jad→patti, **transpiration pull**); **Phloem** (bhojan/translocation, ATP use).

### 6. 🟢 EXCRETION
- 🟢 Nitrogen-waste (urea) nikalna. System: 2 Kidney + Ureter + Bladder + Urethra.
- 🟢 **Nephron** = kidney ki filter ikai. Glomerulus filter → useful cheez **reabsorb** → waste urine.
- 🟢 **Dialysis** = kidney fail hone par machine se filter. Plants: stomata, transpiration, patti girana.

### Example 4 — Artery vs Vein
Artery: heart se, oxygenated, moti, no valve. Vein: heart ko, de-oxy, patli, valves.
