# 🔴 PART A — CORE BASICS (MISS MAT KARNA)

### 🔴 1. Stimulus aur Response
- 🔴 **Stimulus** = environment ka change (garam, roshni, awaaz). **Response** = uska jawab (haath hatana). Control+coordination = ang tal-mel se kaam karein.

### 🔴 2. Cell aur Tissue
- 🔴 **Nervous tissue** = sandesh le jaata; **Muscle tissue** = contract hoke movement.

### 🔴 3. Gland aur Hormone
- 🔴 **Exocrine** (duct se — saliva), **Endocrine** (seedha blood me — hormone). **Hormone** = chemical messenger.

### 🔴 4. Electric vs Chemical signal
- 🔴 Nervous = **tez + short** (electrical). Hormonal = **slow + long** (chemical/blood).

### 🔴 5. Plant idea
- 🔴 Plants me brain nahi, par stimulus pe react (light ki taraf mudna) — hormones se.

# PART B — CHAPTER KA MAIN CONTENT

### 1. 🟢 Nervous System
- 🟢 Control: **Nervous** + **Endocrine**. **Neuron** = nervous system ki ikai.

### 2. 🟢 Neuron Structure — VERY IMPORTANT
- 🟢 **Dendrite** (receive) → **Cell body/cyton** (process) → **Axon** (aage bhejta).
- 🟢 **Synapse** = 2 neuron ki gap; signal electrical→**chemical** (neurotransmitter) ban kar paar.

### 3. 🟢 Reflex Action + Reflex Arc — TOP EXAM AREA
- 🟢 **Reflex** = turant, automatic (garam chhote hatna). Fast bachav.
- 🟢 **Reflex arc:** Receptor → Sensory neuron → **Spinal cord** → Motor neuron → Effector (muscle).
- 🟢 Spinal cord control karta (brain nahi) → isiliye fast.

### 4. 🟢 Human Brain — VERY IMPORTANT
- 🟢 **Fore-brain (Cerebrum):** sochna, yaad, decision, voluntary. Sabse bada.
- 🟢 **Mid-brain:** kuch reflex (eye/pupil).
- 🟢 **Hind-brain:** **Cerebellum** (balance + precise movement), **Medulla** (dhadkan, saans, BP, vomiting), **Pons** (saans).
- 🟢 Suraksha: skull + **CSF** (cushion); spinal cord ko vertebral column.

### 5. 🟢 Voluntary / Involuntary / Reflex
- 🟢 **Voluntary** (marzi se — cerebrum), **Involuntary** (dhadkan/saans — medulla), **Reflex** (automatic — spinal cord).

### 6. 🟢 Coordination in Plants
- 🟢 **(A) Without growth** (immediate): Chhui-mui patti chhoone par band (paani change).
- 🟢 **(B) Tropism** (growth se): **Phototropism** (light), **Geotropism** (gravity — jad neeche/tana upar), **Hydrotropism** (paani), **Chemotropism** (chemical — pollen tube).

### 7. 🟢 Plant Hormones — VERY IMPORTANT (ratta)
| Hormone | Kaam |
|---|---|
| 🟢 **Auxin** | cell lamba; phototropism |
| 🟢 **Gibberellin** | stem/growth badhata |
| 🟢 **Cytokinin** | cell division |
| 🟢 **Abscisic acid** | growth ROKTA (stress, wilting) |

### 8. 🟢 Human Endocrine System — TOP EXAM AREA (ratta)
| Gland | Hormone | Kaam |
|---|---|---|
| 🟢 **Pituitary** | Growth hormone | growth (master gland) |
| 🟢 **Thyroid** | Thyroxine | metabolism; iodine chahiye; kami = **goitre** |
| 🟢 **Pancreas** | Insulin | sugar control; kami = **diabetes** |
| 🟢 **Adrenal** | Adrenaline | fight-or-flight (heartbeat/BP↑) |
| 🟢 Testis | Testosterone | male features |
| 🟢 Ovary | Oestrogen | female features |
- 🟢 **Iodised salt** → thyroxine ke liye iodine (warna goitre). **Feedback mechanism** se hormone level control.
