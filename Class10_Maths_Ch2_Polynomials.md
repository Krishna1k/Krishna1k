## SECTION 1: Foundation — Algebra ki ABCD (Class 7-8-9 ka revision)

### 1.1 Variable kya hota hai?

**Variable** = ek alphabet (jaise x, y, z) jo **kisi unknown number ko represent** karta hai.

**Example:** Maan le tere paas kuch chocolates hain, par tu count nahi jaanta.
Tu kahega "x chocolates hain mere paas". Yahan `x` variable hai.

### 1.2 Constant kya hota hai?

**Constant** = jiska value **fixed** ho.
Numbers like 5, -3, 1/2, pi — sab constant hain.

### 1.3 Algebraic Expression

**Expression** = variable + constant + operations (+, -, x, /) ka mixture.

**Examples:**
- `2x + 5` -> variable x, constant 2 aur 5
- `3x^2 - 7x + 1`
- `5y + 3`

### 1.4 POLYNOMIAL — Asli Definition

**Polynomial** = ek special type ka algebraic expression jisme:
- Variable ke power **whole numbers** (0, 1, 2, 3...) ho
- Power **negative ya fraction NAHI** ho

**Polynomial hai:**
- `2x + 3` (power 1)
- `x^2 - 5x + 6` (power 2)
- `7` (constant, power 0)

**Polynomial NAHI hai:**
- `x^(-2) + 3` (negative power)
- `sqrt(x) + 1` = `x^(1/2) + 1` (fraction power)
- `1/x` = `x^(-1)` (negative power)

### 1.5 Degree of Polynomial

**Degree** = polynomial mein **highest power** of variable.

| Polynomial | Highest Power | Degree |
|---|---|---|
| `2x + 5` | 1 | 1 |
| `3x^2 - 7x + 1` | 2 | 2 |
| `x^3 + 2x^2 - x + 4` | 3 | 3 |
| `7` | 0 | 0 |

### 1.6 Types of Polynomials (degree ke hisab se)

| Degree | Naam | Form | Example |
|---|---|---|---|
| 0 | Constant Polynomial | `c` | 5, -3, 7 |
| 1 | Linear Polynomial | `ax + b` | `2x + 3` |
| 2 | Quadratic Polynomial | `ax^2 + bx + c` | `x^2 - 5x + 6` |
| 3 | Cubic Polynomial | `ax^3 + bx^2 + cx + d` | `x^3 - 2x + 1` |

**Important:** `a != 0` hona chahiye (warna degree change ho jayegi).

### 1.7 Zero/Root of a Polynomial

**Zero** = wo value of `x` jiske liye polynomial ki value `0` ho jaye.

**Easy way to find:** `p(x) = 0` set karo aur `x` solve karo.

**Example:** `p(x) = 2x - 6` ka zero nikaal
```
2x - 6 = 0
2x = 6
x = 3
```
So zero = 3. (Check: p(3) = 2(3) - 6 = 0)
