# 🧮 SOLVED EXAMPLES — Hardest → Easiest

### Solved Example 1 (HARDEST) — Two tangents + angle 🟢
P se PA, PB; angle APB=60. Prove △PAB equilateral.
```
PA=PB → isosceles → angle PAB=angle PBA
60 + 2(angle PAB)=180 → angle PAB=60 → sab 60 → equilateral
```

### Solved Example 2 — Tangent length (Pythagoras) 🟢
Radius 7, OP=25:
```
25² = 7² + PT² → PT² = 576 → PT = 24 cm (7-24-25)
```

### Solved Example 3 — Angle between tangents 🟢
Tangents 70° at P; quadrilateral OAPB (angle OAP=OBP=90):
```
angle AOB = 360 - 90 - 90 - 70 = 110
```

### Solved Example 4 — Equal tangents
PA=10 → PB=10 (equal tangents).

### Solved Example 5 — Tangent length (8-15-17)
Radius 8, OP=17: `PT² = 289-64 = 225 → PT = 15 cm`

### Solved Example 6 — Bisected angle
Tangents 80° → angle OPA = 40 (OP bisects).

### Solved Example 7 — Tangent-radius angle
Hamesha 90° (Theorem 1).

### Solved Example 8 (EASIEST) — Number of tangents
Bahar ke point se → 2 tangents.
