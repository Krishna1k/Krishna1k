## SECTION 1: Foundation

### 1.1 Triangle ki basics yaad kar

- **Triangle** = teen lines se bana figure with 3 angles
- **Sum of angles** = 180°
- Types based on sides:
  - **Equilateral:** sab sides equal, sab angles 60°
  - **Isosceles:** 2 sides equal
  - **Scalene:** sab sides different
- Types based on angles:
  - **Acute:** sab angles < 90°
  - **Right:** ek angle = 90°
  - **Obtuse:** ek angle > 90°

### 1.2 Congruent vs Similar (CRITICAL DIFFERENCE)

| Property | Congruent (≅) | Similar (~) |
|---|---|---|
| Shape | Same | Same |
| Size | **Same** | **May differ** |
| Sides | Equal | **Proportional** |
| Angles | Equal | Equal |
| Symbol | ≅ | ~ |

**Easy:** Photo aur uski xerox copy = congruent. Photo aur uski enlarged copy = similar.

### 1.3 Similar Figures kya hote hain?

**Two figures similar hote hain agar:**
1. Unke corresponding **angles equal** ho
2. Unke corresponding **sides proportional** ho (same ratio mein)

**Examples:**
- Sab squares similar hote hain (lekin sab squares congruent nahi)
- Sab equilateral triangles similar hote hain
- Sab circles similar hote hain

## SECTION 2: Similar Triangles

### 2.1 Definition

Triangle ABC aur Triangle PQR similar hain agar:
1. **∠A = ∠P, ∠B = ∠Q, ∠C = ∠R** (angles equal)
2. **AB/PQ = BC/QR = CA/RP** (sides proportional)

Likhne ka tareeka: **△ABC ~ △PQR**

⚠️ **Order important hai!** Letters ka order corresponding angles dikhata hai.

### 2.2 Example

Agar `△ABC ~ △DEF`, AB = 6, BC = 8, CA = 10, aur DE = 9, toh EF aur FD nikaalo.

```
AB/DE = BC/EF = CA/FD
6/9 = 8/EF = 10/FD
2/3 = 8/EF → EF = 12
2/3 = 10/FD → FD = 15
```

So **EF = 12, FD = 15**.

## SECTION 3: Basic Proportionality Theorem (BPT) — THALES THEOREM

### 3.1 Statement (Important — exam mein aata hai!)

> "If a line is drawn parallel to one side of a triangle to intersect the other two sides in distinct points, then the other two sides are divided in the same ratio."

**Aasaan bhasha:** Triangle ke ek side ke parallel line khichi jaye, jo baaki dono sides ko cut kare, toh wo dono sides **same ratio mein divide** hote hain.

### 3.2 Diagram & Formula

```
        A
       /|\
      / | \
     /  |  \
    D---|---E    <- DE parallel to BC
   /    |    \
  /     |     \
 B------|------C
```

Agar `DE ∥ BC` ho, toh:
```
AD/DB = AE/EC
```

### 3.3 Converse of BPT

> "If a line divides any two sides of a triangle in the same ratio, then the line is parallel to the third side."

Agar `AD/DB = AE/EC` ho, toh **DE ∥ BC**.

### 3.4 Example

Triangle ABC mein, D on AB, E on AC, DE ∥ BC. Agar AD = 2.5 cm, DB = 3 cm, AE = 4 cm, toh EC nikaalo.

```
AD/DB = AE/EC
2.5/3 = 4/EC
EC = (4 × 3)/2.5 = 12/2.5 = 4.8 cm
```

**EC = 4.8 cm** ✅

## SECTION 4: Criteria for Similarity of Triangles

3 main criteria hain — ek bhi prove ho jaye toh triangles similar hain.

### 4.1 AAA (Angle-Angle-Angle) Similarity

> "Agar do triangles ke corresponding **teen angles equal** ho, toh wo similar hain."

### 4.2 AA (Angle-Angle) Similarity

> "Agar do triangles ke corresponding **do angles equal** ho, toh wo similar hain."

(Kyunki teen angles ka sum 180°, isliye 2 same hone se 3rd bhi same)

**Most used criterion!**

### 4.3 SSS (Side-Side-Side) Similarity

> "Agar do triangles ke corresponding **teeno sides proportional** ho, toh wo similar hain."

### 4.4 SAS (Side-Angle-Side) Similarity

> "Agar do triangles ke **do sides proportional** ho aur unke beech ka **angle equal** ho, toh wo similar hain."

### 4.5 Example

Triangle ABC aur Triangle DEF mein:
- AB = 4, BC = 6, AC = 8
- DE = 6, EF = 9, DF = 12

Check:
- AB/DE = 4/6 = 2/3
- BC/EF = 6/9 = 2/3
- AC/DF = 8/12 = 2/3

Sab ratios same → **△ABC ~ △DEF (by SSS)**

## SECTION 5: Pythagoras Theorem (Right-angled Triangle)

### 5.1 Statement (Famous theorem!)

> "In a right-angled triangle, the **square of the hypotenuse** is equal to the **sum of squares of the other two sides**."

```
        A
        |\
        | \
   p    |  \  h (hypotenuse)
        |   \
        |    \
        |_____\
        B  b   C
```

Agar `∠B = 90°`, toh:
```
AC² = AB² + BC²
h² = p² + b²
```

### 5.2 Pythagorean Triplets (Yaad rakh)

Inka use exam mein bahut hota hai:
- **3, 4, 5** → 9 + 16 = 25 ✓
- **5, 12, 13** → 25 + 144 = 169 ✓
- **8, 15, 17** → 64 + 225 = 289 ✓
- **7, 24, 25** → 49 + 576 = 625 ✓

### 5.3 Converse of Pythagoras Theorem

> "Agar triangle ke kisi side ka square baaki do sides ke squares ke sum ke barabar ho, toh wo triangle right-angled hota hai (us hypotenuse ke opposite vertex pe)."

### 5.4 Example

3 cm, 4 cm, 5 cm sides wala triangle right-angled hai ya nahi?

Largest side = 5. Check: 5² = 3² + 4²?
- 25 = 9 + 16 = 25 ✓

**Haan, ye right-angled triangle hai** (right angle 3 aur 4 ke beech).

## SUMMARY

1. **Similar triangles:** corresponding angles equal AND sides proportional.

2. **Congruent vs Similar:** Congruent = same size. Similar = same shape, different size.

3. **BPT (Thales):** Triangle mein parallel line khichne se baaki sides same ratio mein cut hote hain.
   
   `DE ∥ BC` → `AD/DB = AE/EC`

4. **Similarity Criteria:**
   - **AAA / AA:** all/two angles equal
   - **SSS:** all sides proportional
   - **SAS:** two sides proportional + included angle equal

5. **Pythagoras:** Right triangle mein, `(hypotenuse)² = (side1)² + (side2)²`

6. **Famous triplets:** (3,4,5), (5,12,13), (8,15,17), (7,24,25)
