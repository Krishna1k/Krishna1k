## SECTION 1: Foundation

### 1.1 Is chapter mein kya hai?

Chapter 8 mein trigonometry seekhi. Ab use **real-life** mein lagayenge — **heights aur distances** nikaalne ke liye.

Bina pahaadi/building pe chadhe uski height nikaal sakte hain — sirf angle aur distance se! Ye magic trigonometry se hota hai.

### 1.2 Line of Sight

**Line of sight** = aankh se object tak ki seedhi line (jab hum kisi cheez ko dekhte hain).

### 1.3 Angle of Elevation (Upar dekhna)

Jab object hamse **upar** ho (jaise building ka top), toh horizontal line se **upar** wala angle = **Angle of Elevation**.

```
                    * (top of tower)
                   /|
                  / |
   line of sight /  |
                /   |
               /    |
    (eye) ____/_____|
          angle of
          elevation
        (horizontal line)
```

### 1.4 Angle of Depression (Neeche dekhna)

Jab object hamse **neeche** ho (jaise cliff se boat dekhna), toh horizontal line se **neeche** wala angle = **Angle of Depression**.

```
    (eye)________________ horizontal
          \  angle of
           \ depression
            \
             \ line of sight
              \
               * (boat below)
```

⚠️ **Important fact:** Angle of elevation (neeche se upar) = Angle of depression (upar se neeche). (Alternate angles, kyunki dono horizontal lines parallel hain.)

## SECTION 2: Key Approach (How to Solve)

### 2.1 Steps to solve any problem

1. **Diagram banao** (right triangle banta hai)
2. Known angle aur known side mark karo
3. Unknown (height/distance) ko `x` maan lo
4. Decide karo konsa ratio use karna hai:
   - `sin = Opp/Hyp` → use jab Hypotenuse involved ho
   - `cos = Adj/Hyp` → use jab Hypotenuse involved ho
   - `tan = Opp/Adj` → **MOST USED** (height & base)
5. Equation banao aur solve karo

### 2.2 Special angle values (recap)

```
tan 30° = 1/√3 ≈ 0.577
tan 45° = 1
tan 60° = √3 ≈ 1.732
```

(Height/distance problems mein zyadatar `tan` use hota hai)

## SECTION 3: Worked Examples

### Example 1: Simple Tower

"Ek tower ki base se 30 m door khade ho. Tower ke top ka angle of elevation 60° hai. Tower ki height?"

Right triangle: Base = 30 m, angle = 60°, height = h (opposite).

```
tan 60° = h / 30
√3 = h / 30
h = 30√3 = 30 × 1.732 = 51.96 m
```

**Tower ki height = 30√3 m ≈ 51.96 m** ✅

### Example 2: Finding Distance

"Ek 15 m unchi building ke top se ek car ka angle of depression 45° hai. Car building se kitni door?"

Angle of depression = angle of elevation = 45° (alternate). Height = 15 m, distance = d.

```
tan 45° = 15 / d
1 = 15 / d
d = 15 m
```

**Car 15 m door hai.** ✅

### Example 3: Ladder Problem

"Ek ladder ground se 60° angle banati hai. Ladder ka foot wall se 2.5 m door hai. Ladder ki length?"

Base (adjacent) = 2.5 m, ladder = hypotenuse = L, angle = 60°.

```
cos 60° = adj / hyp = 2.5 / L
1/2 = 2.5 / L
L = 5 m
```

**Ladder ki length = 5 m.** ✅

### Example 4: Two Angles (thoda mushkil)

"Ek tower ke base se kuch door se top ka angle of elevation 30° hai. 20 m aur paas aane par 60° ho jaata hai. Tower ki height nikaal."

Let height = h, near distance (base se) = x. Far point = (x + 20).

```
From near point: tan 60° = h/x      → h = x√3       ...(1)
From far point:  tan 30° = h/(x+20)
                 1/√3 = h/(x+20)
                 h√3 = x + 20                        ...(2)

Put (1) in (2):
(x√3)(√3) = x + 20
3x = x + 20
2x = 20 → x = 10

h = x√3 = 10√3 ≈ 17.32 m
```

**Tower height = 10√3 m ≈ 17.32 m.** ✅

## SUMMARY

1. **Line of sight:** aankh se object tak seedhi line.
2. **Angle of elevation:** object upar ho (upar dekhna).
3. **Angle of depression:** object neeche ho (neeche dekhna).
4. **Elevation angle = Depression angle** (alternate angles).
5. **Solving steps:** Diagram → ratio choose karo (tan/sin/cos) → equation → solve.
6. `tan` zyadatar use hota hai (height aur base ka rishta).
