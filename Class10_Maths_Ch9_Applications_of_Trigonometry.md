# 🧮 SOLVED EXAMPLES — Hardest → Easiest

### Solved Example 1 (HARDEST) — Do angles (2 positions) 🟢
Base se elevation 30; 20 m paas aane par 60. Height?
```
tan60 = h/x → h = x√3   ...(1)
tan30 = h/(x+20) → h√3 = x+20   ...(2)
3x = x+20 → x=10 → h = 10√3 = 17.32 m
```

### Solved Example 2 — Depression (boat) 🟢
20 m cliff, depression 30:
```
tan30 = 20/d → d = 20√3 = 34.64 m
```

### Solved Example 3 — Kite (string) 🟢
Dori 100 m, angle 60:
```
sin60 = h/100 → h = 50√3 = 86.6 m
```

### Solved Example 4 — Simple tower (60)
Base 30 m, elevation 60: `tan60 = h/30 → h = 30√3 = 51.96 m`

### Solved Example 5 — Find distance (45)
15 m building, elevation 45: `tan45 = 15/d → d = 15 m`

### Solved Example 6 — Ladder (cos)
Angle 60, foot 2.5 m: `cos60 = 2.5/L → L = 5 m`

### Solved Example 7 — Tower (45, base 40)
`tan45 = h/40 → h = 40 m`

### Solved Example 8 (EASIEST) — Concept
Elevation = object upar; Depression = object neeche.
